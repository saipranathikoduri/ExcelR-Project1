# Art For You — Full Stack E-Commerce Website

A handmade products e-commerce website built using React, Vite, Java 17, Spring Boot, Spring Data JPA and MySQL.

## Technologies Used

- Frontend: React, Vite, JavaScript, CSS
- Backend: Java 17, Spring Boot, Spring Data JPA
- Database: MySQL
- API: REST APIs
- IDE: Eclipse, Visual Studio Code

## Features

### Customer Features
- View product collections and products.
- Browse product images and prices.
- Place orders through checkout.
- View order total and advance payment amount.
- Find orders using mobile number.
- Track order status and tracking ID.
- View India Post tracking information.
- Submit payment proof for admin verification.

### Admin Features
- Admin login and logout.
- View customer orders.
- Update order status and tracking details.
- View and verify payment proof manually.
- Manage product visibility and catalogue information.

## Project Structure

- `frontend/` - React application
- `backend/` - Spring Boot REST API
- `assets/` - Original project assets

## Requirements

- Java 17 or later
- Node.js and npm
- Eclipse IDE
- MySQL
